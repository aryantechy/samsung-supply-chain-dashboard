# Samsung Supply Chain & Logistics Dashboard

## 📊 Overview

An interactive **Power BI dashboard** built to analyze Samsung's supply chain and logistics operations.

The dashboard provides a consolidated view of **suppliers, inventory, shipments, customers, revenue, costs, and operational performance**, allowing users to explore key business metrics through interactive visualizations and filters.

## 🎯 Objectives

- Monitor overall supply chain performance
- Analyze supplier performance and lead times
- Track inventory levels and stock availability
- Analyze shipment delays and delivery performance
- Understand customer revenue and sales channels
- Identify important trends and operational insights

## 📌 Dashboard Pages

### 🏠 Home
Provides an interactive landing page with navigation to the major dashboard sections.

### 📈 Overview
Provides a high-level summary of the supply chain with KPIs such as:

- Gross Revenue
- Total Revenue
- Profit
- Profit Margin
- Perfect Order %
- Order Quantity
- Inventory Quantity
- Shipment Quantity
- Delivered Shipments

It also includes visual analysis of supplier lead time, inventory stock, shipment delays, and revenue by customer/platform.

### 🏭 Supplier
Analyzes supplier performance using:

- Average Lead Time
- Unit Cost by Month
- Total Unit Cost
- Order Quantity
- Average Quality Score
- Supplier-level performance comparisons

### 📦 Inventory & Production
Provides insights into:

- Inventory Value
- Safety Stock
- Turnover Rate
- Days of Inventory
- Defective Units
- Defect Rate
- Current Stock
- Reorder Point

Monthly trends for inventory value and defective units are also visualized.

### 🚚 Shipment
Analyzes logistics and delivery performance using:

- Total Shipments
- Shipment Cost
- Total Delay
- Delivered Shipments
- Delivery Percentage
- Carrier-wise delays
- Shipment cost trends
- Delay reasons
- Shipment status

### 👥 Customer
Analyzes customer and sales performance through:

- Gross Revenue
- Total Revenue
- Profit
- Profit Margin
- Perfect Order %
- Quantity Sold
- Discounts
- Revenue by Channel Type
- Revenue by Customer/Platform

## 🚀 How to Use

1. Download the `.pbix` file from this repository.
2. Open it using **Microsoft Power BI Desktop**.
3. Refresh the data if required.
4. Navigate between the dashboard pages using the built-in navigation buttons.
5. Use the available filters and interactive visualizations to explore the data.
